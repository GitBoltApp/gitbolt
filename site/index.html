Features

Highlights

A Rust core reads with gitoxide and writes through the git command line. Every action is in the command palette (Ctrl+P), and every shortcut is listed in Help (Ctrl+/).

Compared with GitKraken

If you've used GitKraken, GitVolt will feel familiar: the lane graph down the middle, the branch and remote sidebar, the commit details on the right. GitVolt is an independent project, not affiliated with or endorsed by GitKraken / Axosoft.

Privacy

No account. No telemetry.

Your repositories and tokens stay on your machine. The webview can't reach the network on its own; the Rust core makes every request.

No account, no telemetry

No analytics or crash reporting. The update check is the only request GitVolt makes on its own that isn't about your repositories or accounts.

Locked-down webview

A strict Content Security Policy, and Chromium can't resolve any host name but localhost: the Rust core makes every network request.

Images on a click

Images from hosts other than your forge load only after you click them.

Tokens in the keyring

Forge tokens stay in the system keyring, never in a file or a log.

Your system's git

Writes go through the git command line, so your hooks, config and credentials behave as they always do.

This site

No cookies, no analytics, no third-party scripts. The demo runs in your browser and sends nothing.
